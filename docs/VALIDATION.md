# 实际验证记录

日期：2026-10-22（Asia/Shanghai）。下列结果来自本机实际执行，不代表论文基准复现。

## 环境与默认配置

- AMD Ryzen 7 9700X，8 核 / 16 线程，约 30 GiB 系统内存。
- NVIDIA RTX 5060，8151 MiB 显存。
- GTNH 2.8.4 / Minecraft 1.7.10，复用 HMCL 已安装资源和 Java 25。
- 独立客户端堆上限 6 GiB，测试服务端 4 GiB。
- 测试副本采用和平难度、服务端视距4；与原始困难难度不同。
- GameScaling-9B-S1 Q4_K_M，配套 FP16 视觉编码器；llama.cpp build 10394 / commit 680a9ae63。
- 默认 GPU 卸载8层和视觉编码器，8192上下文，单请求槽；其余模型在内存。
- 同时运行游戏与模型时，观察到显存合计约4.1–4.4 GiB，可用内存约11–12 GiB。不是峰值保证。

## 已验证

1. 测试服务端实际完成启动，客户端专用离线角色 GameScalingBot 连接成功。
2. 真实截图来自客户端渲染缓冲，尺寸854×480，约每秒更新；观察台已通过浏览器显示检查。
3. 200ms W动作包导致位置变化约0.86格，X方向鼠标位移导致实际偏航变化；包结束后停止移动。
4. E打开GuiInventory，Esc关闭，修复后无桥接错误。
5. 右键任务书进入GuiHome；模拟本地鼠标事件点击Quests进入GuiQuestLines，点击书签进入GuiBookmarks。这些是显式桥接功能测试，不能记为模型自主解题。
6. 首批14轮真实截图模型决策均成功解析；其中2轮包含模型实际生成的推理文字。后续记录格式加入执行确认，6轮已有显式客户端确认字段；更早动作通过位置与完成包另行验证。
7. 视觉CPU、8层GPU配置测得多轮约12–19秒；历史重算时曾约62秒。将视觉编码器也放GPU后，若直接输出动作，测得约4.4–5.6秒；带推理的轮次更长。
8. 纯CPU配置实际完成一轮任务书截图推理：27.50秒，输出合法动作包。该输出未执行。
9. 三项协议测试通过：与官方聊天模板逐字符对齐；不执行未闭合动作；不将未闭合推理中引用的动作当作真实动作。
10. 量化文件原始SHA256与下载元数据一致。MTP元数据修复前后完整张量区域SHA256一致，见根目录JSON记录。
11. 隐藏窗口后实测 GLFW `VISIBLE=false`、`FOCUSED=false`、光标模式为普通模式；30 FPS 渲染和截图继续更新。GPU 上下文仍保留。
12. 客户端内回放5种硬件输入回调（移动、按钮、滚轮、键盘、字符），均被隔离；鼠标坐标、事件队列和实际视角未被改变。独立虚拟W/左键的按下、释放及点击事件轮询通过。这是回调入口验证，没有声称做过人工实体键鼠测试。
13. 隐藏且无焦点时，200ms虚拟W动作实际水平移动0.534格，虚拟鼠标改变偏航；E打开GuiInventory，Esc关闭，包结束后释放输入。证据为私有 `runtime/input-isolation-validation.json`，可用 `scripts/verify_input.py` 重跑。
14. 观察台“在线玩家”按钮实际返回GameScalingBot；手动输入`/gamerule keepInventory`返回`keepInventory = true`；白天、晴天快捷按钮均收到真实回显。命令窗口不等待模型推理。
15. 测试服务器实际返回`Set game difficulty to Peaceful`；开启keepInventory后save-all，读取压缩NBT存档确认该规则已保存为true。服务器重启由启动属性与观察服务恢复默认规则。
16. 手动命令暂停自动操作后，第69轮在途推理完成但没有执行，其证据记录`executed=false`及场景已变更的丢弃原因。HTTP多行输入返回400，外部来源返回403。
17. 共7项测试通过，包括原3项动作协议测试及新增4项命令协议测试。证据为私有`runtime/server-console-validation.json`与命令日志。
18. 根目录stop.sh实测约3秒正常停止四个服务；last-stop.json记录所有本项目进程列表为空，25565/25575/8789/8790均未监听，服务器日志确认保存与维度卸载。
19. 随后从全停状态执行start.sh --no-open，首次含模型校验约82秒确认全部就绪，客户端隐藏、无焦点、鼠标自由，服务器规则恢复，模型自动操作开启。
20. 实际移走四个PID文件后重复启动，脚本恢复的四个PID与之前完全一致；--paused确认自动操作保持暂停。新增进程识别、PID复用防误杀、异常继续清理等测试，与前述协议测试合计12项通过。启停验收记录在私有runtime/lifecycle-validation.json。

## 实际观察到的限制

- S1会误识别GTNH画面。例如一轮将任务书描述为斧头/镐，未在画面中得到充分支持。
- 已提取安装包前两项任务的真实数量要求加入提示，但没有在GTNH上微调。
- 已验证连接、截图、动作闭环和部分GUI交互；尚未验证完成第一任务、合成链、长期科技推进或数小时无人值守。
- GPU/CPU切换会重建推理服务；实际接口媒体占位符随服务重启变化，客户端会重新查询。
- 子步骤按客户端渲染事件调度，Minecraft服务端仍以自身tick处理动作。
- 隐藏窗口仍需要桌面图形会话；注销桌面或GPU上下文丢失不在本次验证范围。输入隔离agent针对当前整合包版本，升级lwjgl3ify需要重新验证。

运行证据在私有 `runtime/` 与 `logs/`，与完整本地备份一起保存；GitHub源码包仅保留本记录及可复现脚本，不包含世界和模型文件。
