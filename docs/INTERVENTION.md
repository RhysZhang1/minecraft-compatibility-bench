# 临时手动干预

[English](INTERVENTION.en.md) · [返回首页](../README.zh-CN.md)

模型反复打开背包、停留在菜单或被地形卡住时，可以在观察台直接操作同一个后台角色。无需切出客户端窗口，不接管桌面键盘和鼠标。

## 使用方法

1. 查看观察台的最新游戏画面。
2. 点击“启用画面点击 / 拖动”。模型随即暂停，正在生成的旧动作作废，现有按键与挖掘长按释放。
3. 在背包、菜单、工作台或熔炉等界面内，直接点击预览图。左键拿起/放下，右键按游戏原有规则拆分物品。按住并拖动会发送带持续按压的移动轨迹；拖动分配物品通常需要先点击拿起一叠物品。勾选 Shift 后可进行 Shift 点击。
4. 游戏内使用下方移动、跳跃、攻击/挖掘、交互和视角按钮。单次按键可选 100ms、300ms、1秒或2秒；不是持续远程键盘捕获。滚轮按钮可切换快捷栏。
5. 有异常时点击“释放全部输入”。完成后点击“交还模型”，让模型基于新观测继续。关闭画面点击模式本身不会恢复模型。

手动动作结束后保持暂停，可连续操作。移动和鼠标键最多长按2秒；GUI拖动还包含定位、按下及释放间隔，总长最多约2.18秒。手势越出画面会被限制在边缘；触摸取消不会发送动作。

## 输入隔离与取消

操作通过已有私有显示会话的 libei 输入通道发送，不向用户桌面注入全局输入。页面不会捕获用户在其他应用中的键鼠操作。只有显式操作面板按钮或启用后的预览图才会发往游戏。

人工操作与模型动作共用控制世代和心跳。接管、紧急释放、客户端重连、界面变化或心跳超时会取消旧动作并释放输入。人工动作进行时不能恢复模型或切换实例。陈旧会话或已变化界面上的点击会被拒绝，应查看新画面后重试。

打开背包或点击菜单按钮本身可能改变界面，面板此时提示“界面或控制状态已变化，输入已释放”。这不表示点击必然失败，应以新画面为准。游戏内直接点击预览图不会转动视角，请使用视角按钮。

## 记录和适用范围

人工操作单独保存至对应实例 `interventions/`，包含 `source: human`、输入计划、完成/取消状态与前后画面。它们不增加模型决策次数，也不进入模型动作回放集。续玩记忆可以记录操作后的真实位置和背包事实，不能据此宣称模型完成了任务。

此功能需要更新后的 `virtual-x11` 私有显示后端及 `manual_input` 能力；旧版 Forge 专用桥接不支持时面板会禁用操作。具体整合包仍需要匹配客户端，特殊界面按游戏自身规则处理。人工拖动不改变上游模型的200ms动作协议，也不代表模型已具备拖动、合成或熔炉规划能力。

服务依然仅监听本机；远程使用请沿用首页的 SSH 转发方式。

## 本机验收

2026-10-23 在原版1.20.1及真实隐藏客户端中验证：面板按键打开/关闭背包，预览图点击拿起30个泥土，拖动分成三个各10个的槽位，再通过 Shift 点击合回原快捷栏。2秒长按期间恢复请求被拒绝，紧急释放后约52ms观测到空按键与空闲状态；这是单次本机测量，不是延迟保证。交还模型后真实决策恢复，再暂停时无残留按键或挖掘。未逐一验收其他版本的人工拖动或特殊模组GUI。
