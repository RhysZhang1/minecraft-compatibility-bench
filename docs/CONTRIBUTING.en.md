# Development and architecture

[简体中文](CONTRIBUTING.md)

This project owns compatibility and evaluation, not model capability. Distinguish model output, parsing, client acknowledgement, observed changes and verified task completion. Observed changes do not establish task completion. Use English comments, docstrings and new identifiers; localized UI strings may be Chinese.

```bash
python3 -m venv .venv
.venv/bin/pip install -e '.[dev]'
.venv/bin/ruff check mcbench scripts tests
.venv/bin/ruff format --check mcbench scripts tests
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/mcbench replay tests/fixtures/golden/replay.json
.venv/bin/python -m build --wheel
```

| Module | Responsibility |
|---|---|
| mcbench/runtime.py | Explicit state, locks, cancellation epoch, dependencies and worker startup |
| mcbench/loop.py | Serial inference, completion acknowledgements, fresh frames and memory scheduling |
| mcbench/prompt.py | Checkpoint protocol, image history, stable prefix and live context |
| mcbench/feedback.py | Observation comparison, idle streaks and repeated screen cycles |
| mcbench/decisions.py | Pure execution authorization and recovery/pause decisions |
| mcbench/http.py | Local routes, request validation and dashboard resources |
| mcbench/services.py | RCON, process resources, GPU telemetry and status snapshots |
| mcbench/memory.py | Per-world facts, user notes and unverified suggestions |
| mcbench/tools/ | Deployment, installation, build, lifecycle and snapshot tools |

Runtime explicitly composes PromptBuilder, DecisionLoop and RuntimeServices with references to the same runtime. There is no cross-module global state singleton. Importing runtime modules reads no instance and starts no threads. Short scripts/ launchers preserve previous commands by executing package modules without sys.path edits. Installed wheels support replay APIs outside the checkout; live tools additionally need a source workspace with Java/C sources and configuration.

Preserve these invariants: parsing alone cannot authorize execution; enabled/epoch/session must match. Require a matching, fresh observation after acknowledgement. Pause, disconnect, target changes and expired heartbeat release mining. Only LB may sustain under its bounded lease; movement keys cannot. Recovery observes again, trims history and eventually pauses; it does not choose a button for the model. Unknown sensor data is not an empty inventory.

Fixture expectations must be committed constants with provenance, never regenerated by the implementation during tests. Label recorded observations separately from authored boundary mutations. See tests/fixtures/README.en.md. CI runs offline replay and installed-wheel checks; real game acceptance still needs explicit platform/version evidence.

Original code uses GPL-3.0-or-later. Do not reformat or relicense vendor code. Java -javaagent remains a standard JVM term, independent of product branding. Do not commit worlds, models, credentials, private notes or raw runtime directories.
